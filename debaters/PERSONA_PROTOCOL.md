# 辩手人设加载协议（PERSONA_PROTOCOL）

## 1. 每位辩手的资料结构

```text
debaters/<name>-perspective/
├── SKILL.md                         # 人设 DNA：核心镜片 / 决策启发式 / 表达 DNA / 工具箱 / 诚实边界
└── references/research/
    ├── 01-writings.md               # 著作、文章、代表性观点
    ├── 02-conversations.md          # 经典辩论场景、即兴交锋
    ├── 03-expression-dna.md         # 表达风格特征、句式、口头禅
    ├── 04-external-views.md         # 外界评价（含被认为的弱点）
    ├── 05-decisions.md              # 打法选择与关键决策
    └── 06-timeline.md               # 经历时间线（仅作背景）
```

## 2. 渐进加载表（只加载当前环节在场的辩手）

| 环节 | 必读 | 按需 | 目的 |
|---|---|---|---|
| 阶段 A 选角 | 全部 `SKILL.md` 的 frontmatter 与「诚实边界」 | — | 匹配辩位，避开人设短板 |
| B1 论点架构 / B3 攻防演练 | `SKILL.md` | `05-decisions.md`、`04-external-views.md` | 打法偏好（加法/减法）、自知的弱点 |
| 申论 / 一辩稿 / 结辩 | `SKILL.md` | `03-expression-dna.md`、`01-writings.md` | 句式、节奏、金句模板 |
| 质询 / 自证 / 自由辩 | `SKILL.md` | `02-conversations.md`、`03-expression-dna.md` | 即兴反应、追问习惯 |
| 赛后彩排 H1–H5 | `SKILL.md` | `05-decisions.md` | 复盘口吻 |
| 协同提问「原辩手 / 对方辩手」 | `SKILL.md` | 与问题相关的一份 research | 第一人称作答 |

- **isolated 模式**：每个辩手子代理只加载自己的资料；编排器不加载辩手 research。
- **inline 模式**：同一时刻只加载「本环节发言者」的资料，环节结束即不再引用，避免 8 份人设互相串味。
- 单个环节加载的 research 总量建议 ≤ 2 份；先读文件的目录/小标题，再读需要的小节。

## 3. 护栏（必须遵守）

1. **只用公开的辩论人格**：辩论风格、公开言论、公开赛事记录。research 中出现的私生活内容
   （婚恋、家庭、纠纷、绯闻等）**一律不得进入任何发言、评语或稿件**。
2. **不伪造「真人原话」**：research 中的引语来自公开资料整理，不保证逐字准确；
   发言里可以借鉴风格与观点，但不要写「我在某年某节目说过……」之类可被当作事实引用的陈述，除非 research 中确有记载。
3. **学风格，不学冒犯**：个别辩手卡中收录的争议性金句（带性别/群体标签的说法）只作为风格参考，
   **不得在辩论中复用针对任何群体的贬损性标签**。
4. **尊重诚实边界**：每张辩手卡末尾的「诚实边界 / 适用边界」是选角与分工的依据，
   例如擅长短平快的辩手不安排需要长铺垫的环节。
5. **模拟声明**：所有发言均为基于公开资料的 AI 风格模拟，不代表真实人物观点；
   协同台与 `debate_ctl.py export` 导出的文件默认附带该声明。

## 4. 发言标签规范（与协同台、lint 对齐）

段首加粗 + 冒号：`**正方一辩 · 胡渐彪**：……`；备注写在标签后：`**正方二辩 · 颜如晶**（打岔 1/3）：……`。
赛前/赛后的本方会议可只写辩位与姓名：`**一辩 · 胡渐彪**：……`（阵营由文件所属方推断）。
